## 📖 Design & Architecture

The site takes inspiration from **Swiss modernism** and broadsheet editorial layouts:

* **Visual Identity:** Warm ecru paper backdrop (`#F4EFEA`), ink-black typography (`#111111`), and crisp vermilion red accents (`#E03A24`).
* **Performance:** Pure vanilla HTML5 and CSS3 with zero external JavaScript frameworks, delivering instantaneous load times.
* **Layout Structure:**
  * **Desktop:** Full-viewport view (`100vh`) with CSS scroll-snapping for a slide-deck presentation feel.
  * **Mobile:** Fluid, airy vertical spacing designed for effortless reading on smaller screens.
* **Standards & Accessibility:** Fully structured using semantic HTML tags (`<section>`, `<article>`, `<header>`) for clean DOM hierarchy and accessibility compliance.
